# Day 006 Notes

## Key Takeaways
- Lists are mutable (can be changed)
- Use append() to add to end, insert() for specific position
- pop() removes and returns last item (or item at index)
- List comprehensions are faster than loops

## Common List Methods
- append(x) - Add item to end
- insert(i, x) - Insert at position
- remove(x) - Remove first occurrence
- pop(i) - Remove and return item
- sort() - Sort in place
- reverse() - Reverse in place
- count(x) - Count occurrences
- index(x) - Find first index
